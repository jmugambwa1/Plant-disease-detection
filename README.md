# Plant Disease Detection System

## Overview
This project is a machine learning-based plant disease detection system designed to identify diseases in plants using image analysis and predictive models.

The system combines:
- A frontend web application for user interaction
- A Python backend for disease prediction
- Machine learning models for classification

## Features
- Upload plant images
- Predict plant diseases
- User-friendly web interface
- Machine learning prediction system
- Fast and responsive frontend

## Technologies Used

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Python
- Pandas
- Scikit-learn

## Installation

### Clone Repository

```bash
git clone https://github.com/jmugambwa1/Plant-disease-detection.git
cd Plant-disease-detection
```

### Backend Setup

```bash
pip install -r requirements.txt
python main.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## Machine Learning Model
The model was trained using plant disease datasets and used for disease classification and prediction.
